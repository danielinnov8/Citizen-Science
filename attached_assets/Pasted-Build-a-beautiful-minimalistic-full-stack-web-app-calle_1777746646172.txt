Build a beautiful, minimalistic full-stack web app called “Citizen Science.”

The product should feel like a premium Apple-meets-Notion-meets-Khan Academy platform for people who want to learn, simulate, track, and run their own experiments across life sciences and adjacent scientific fields.

The app has two main layers:

1. A public marketing website
2. A logged-in user dashboard with experiment categories, tutorials, simulators, tools, and progress tracking

Use a modern stack:
- React
- TypeScript
- Tailwind CSS
- Supabase or Firebase for auth/database
- Google OAuth login
- Clean component-based architecture
- Responsive design
- Beautiful animations, but subtle
- Minimalistic, scientific, trustworthy visual identity

Brand feeling:
- Clean
- Intelligent
- Inspiring
- Scientific but approachable
- Premium but not corporate
- Minimal but not empty
- Soft white background with light gray sections
- Accent colors: deep blue, soft green, and subtle violet
- Use elegant typography, generous spacing, rounded cards, soft shadows, and clean icons

Core concept:

Citizen Science helps everyday people explore science through guided experiments, simulations, and structured learning tools. Users can choose a field, follow a short tutorial, use an interactive simulator or experiment planner, log their own observations, and track progress over time.

EXPERIMENT WORKFLOW

Each experiment should have a structured workflow:

1. Objective
What are we trying to learn?

2. Hypothesis
User writes a prediction.

3. Variables
- Independent variable
- Dependent variable
- Controlled variables

4. Materials
List safe materials.

5. Procedure
Step-by-step instructions.

6. Data Collection
Table for measurements.

7. Observations
Freeform notes.

8. Results
User summarizes what happened.

9. Reflection
What would they change next time?

10. Save Experiment
Save to dashboard/notebook.

IMPORTANT SAFETY REQUIREMENTS

Citizen Science must never encourage dangerous experiments.

Add disclaimers across relevant tools:
- Educational use only
- Do not ingest unknown substances
- Do not culture unknown microbes
- Do not mix chemicals unsafely
- Do not perform medical experiments
- Do not use this as medical advice
- Use protective equipment where appropriate
- Minors should work with adult supervision
- Follow local laws and safety guidelines

For microbiology:
Do not provide instructions for culturing unknown bacteria or pathogens. Keep it simulation-based or sealed observation only.

For chemistry:
Only safe household-level demonstrations. No hazardous combinations.

For health:
Track wellness only. No diagnosis, treatment, or medical claims.
